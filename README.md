# 👟 KickFit – Premium E-Commerce Shoe Platform

**KickFit** is a high-performance web application designed for sneakerheads and footwear enthusiasts. Developed using **PHP** and **MySQL**, the platform offers a seamless shopping experience—from high-performance athletic runners to classic formal leather shoes.

---

## 🚀 Core Features

* **🔐 Secure Authentication:** Integrated user registration and login system with session management.
* **🛒 Shopping Cart & Checkout:** Real-time "Add to Cart" functionality with a streamlined checkout flow.
* **📦 Shoe Catalog by Category:** Organized product listings for **Men**, **Women**, and **Kids**.
* **👤 User Dashboard:** Personal space for users to manage profiles and view their shoe collections.
* **🛠️ Admin Management Panel:** Dedicated backend for admins to manage stock, update prices, and add new shoe arrivals.
* **🗄️ Database Integration:** Relational MySQL design for fast, efficient product queries.
* **🎨 Responsive UI:** A modern, mobile-friendly design crafted with CSS3 and JavaScript.

---

---

## 📂 Project Structure

* `/assets` – Product images, CSS stylesheets, and JavaScript files.
* `/admin` – Administrative scripts and management dashboard.
* `/includes` – Database connection strings and reusable PHP functions.
* `/sql` – Database schema and product `INSERT` queries.

---

## ⚙️ Quick Setup

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/iam-rishab07/KickFit.git](https://github.com/iam-rishab07/KickFit.git)
    ```
2.  **Database Configuration:**
    * Open **phpMyAdmin**.
    * Create a database named `kickfit`.
    * Import the `.sql` file found in the `/sql` folder.
3.  **Connection Setup:**
    * Update your database credentials in `includes/db_connect.php`.
4.  **Run the Project:**
    * Move the project folder to your XAMPP `htdocs` directory.
    * Open your browser and go to `localhost/KickFit`.
